# Serpent Halo 视觉方向

## 方向

“暗室里的活体珠宝”。视觉核心不是新增粒子，而是原作者的程序化蛇：数百枚压扁八面体鳞片沿无尽曲线滑动，青绿皮肤间浮出珊瑚红斑点，湿润高光在黑场里连续转折。创新只发生在一次完成仪式中，让同一条蛇的现有材质产生尾到头的银白脉冲。

## 原版基线合同

- 源码：`https://github.com/Sujenphea/procedural-snake`，固定 commit `fce15746389d8a358be228d92d3c82fb989be915`，MIT。
- 保留：`CurveGenerator` 的 seek/orbit/coil/wander、`EndlessCurve` 的滑动窗口与并行传输帧、位置/法线 DataTexture、八面体 InstancedMesh、原 snake vertex/fragment shader、原相机和发光球。
- `?baseline=1`：显示原 Codrops 标题与链接，关闭所有新增 UI、仪式进度、幽灵手指、音频和材质脉冲。开发环境允许原 lil-gui/debug 继续出现，生产环境与原版一致不出现。
- 默认模式不得用 TubeGeometry、样条线贴图、视频或预渲染动画替代上述源码结构。

## 色彩与材质

- 背景：`#000000`，无渐变、无星空、无雾化贴图。
- 蛇体基色：保留 `#2a9d8f`；斑纹：保留 `#e76f51`；目标球：保留 `#44ddff`。
- UI 主色：`rgba(238,245,241,.86)`；弱文字：`rgba(238,245,241,.48)`；进度环：`rgba(68,221,255,.7)`。
- 完成脉冲只把局部材质混向 `#f4fff9`，最大宽度占蛇长 11%；禁止彩虹色相循环、镜头闪白、碎片爆炸和额外光点喷射。

## 排版与布局

- 字体使用系统 `ui-monospace, SFMono-Regular, Menlo, monospace`，延续原 Codrops 实验标本气质。
- 顶部安全区：距顶 `max(18px, env(safe-area-inset-top)) + 8px`，左侧 18 px；标题 `SERPENT HALO` 为 11 px、字距 0.18em，下一行编号 `STUDY 03 / PROCEDURAL COIL` 为 9 px、透明度 .48。
- 底部提示距 `env(safe-area-inset-bottom)` 上方 24 px，水平居中，10 px、字距 .14em；没有面板、胶囊按钮、设备外框或大号营销标题。
- 目标进度环是 46 px 细圆环，跟随光珠的屏幕坐标；完成时最大扩张至 128 px，不阻挡蛇体。

## 动效与反馈

- 指针到目标球继续使用原版 `lerp(..., 0.1)`，保留有机滞后。
- 进度环每帧只更新 CSS 变量 `--progress` 与 transform；不得触发框架重渲染。
- 幽灵手指使用项目统一的 Google Material `touch_app` 实心路径，44×44 区域，3.2 秒走一个不完整圆；球和蛇必须真实跟随同一屏幕坐标。
- 完成脉冲前沿使用 `smoothstep` 构成 11% 宽度窄带，沿 `vSpineU` 从 0 到 1 前进；同时把 Fresnel 强度最多从 .3 提到 .68，1.8 秒后完全回到原参数。

## 响应式与性能

- 目标尺寸为 390×844 与 320×568；短屏底部提示上移 12 px，顶部只保留两行。
- 继续使用原作者移动端 50×6=300 个鳞片实例和 DPR 1；桌面使用 100×8=800 个实例与设备 DPR。
- 页面不可滚动，画布固定全屏；DOM UI 不接受 pointer 事件。
- `prefers-reduced-motion` 下不自动演示幽灵手指，完成脉冲缩短到 500 毫秒且不改变目标位置。

## 反模式

- 不把它改成传统贪吃蛇，不加入方向键、食物、分数、死亡或障碍。
- 不叠加玻璃碎片、烟花、星空、霓虹网格、HUD 卡片或手机设备外框。
- 不改变原蛇体轮廓和鳞片密度来“做得更像蛇”；视觉可信度必须来自上游 shader 与路径系统。
- 不用纯文字说明代替首次演示，也不允许幽灵手指与真实目标球脱节。
