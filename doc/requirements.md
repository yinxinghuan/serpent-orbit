# Serpent Halo 需求文档

## 1. Overview

Serpent Halo 是一个 8–12 秒完成一次的单手感官玩具：玩家拖动发光珍珠绕出一圈，GPU 实例化灵蛇沿无尽三次贝塞尔曲线追逐并盘绕，完成时整条鳞片产生一次从尾到头的高光脉冲，然后自动复原。

## 2. Visual Design

基线必须直接建立在 Sujen Phea / Codrops 的 MIT 源码 `Sujenphea/procedural-snake@fce15746389d8a358be228d92d3c82fb989be915` 上，保留纯黑背景、45° 透视相机、青绿色底色、珊瑚红斑纹、八面体实例鳞片、发光目标球、椭圆截面、腹部提亮、Fresnel 轮廓光和各向异性高光。默认体验隐藏原作者演示页导航与开发参数面板，只增加顶部小标题、底部单句动词提示、目标球周围的细线进度环和 Google Material `touch_app` 幽灵手指。完整界面系统见 `doc/visual.md`；`?baseline=1` 保留原版界面与行为，作为视觉回归基准。

## 3. Game Mechanics

- 原版蛇体保持 10–26 世界单位长度、50–100 个脊柱采样、6–8 个径向实例、每秒 4 世界单位前进速度；移动端沿用原作者低质量档，桌面沿用高质量档。
- 路径继续由 seek、orbit、coil、wander 与最大转向角共同生成；每段三次贝塞尔曲线长度为 4–8 世界单位，并使用并行传输坐标架避免截面翻转。
- 玩家按下时记录指针相对屏幕中心的极角；有效半径为屏幕短边的 18%–58%，累计同向角位移达到 `1.65π` 后完成仪式。反向抖动每帧最多抵消 `0.045π`，避免轻微手抖清空进度。
- 完成后进入 1.8 秒 `halo` 状态：目标球在 320 毫秒内回到屏幕中心，蛇体继续使用原曲线追踪；shader 中新增的单一 `u_ritual` 值从 0→1→0，驱动尾到头的窄带高光、斑纹轻微流动和 Fresnel 强度提升。
- 结束后用 700 毫秒恢复原材质参数，进度归零并回到 `idle`；没有积分、关卡或永久失败。
- 首次 1.2 秒无输入后，幽灵手指用 3.2 秒绕出 0.78 圈；它必须同步更新原版目标球和蛇体追踪，不得只做装饰动画。首次真实按下立即永久隐藏本次会话引导。

## 4. Controls

- Pointer / Touch：`pointerdown` 开始仪式，`pointermove` 拖动光珠，`pointerup` 暂停累计但保留当前进度 2.4 秒；超时后在 900 毫秒内缓慢回落到 0。
- Mouse：移动光标仍保留原版的自由追随；只有按住主键并形成环绕才累计完成进度。
- Keyboard：按 `Space` 可在无精确指针设备上让目标沿预设圆周前进，持续 2.8 秒即可完成一次仪式。
- 画布区域使用 `touch-action: none`，所有触控目标和可点击控件若出现必须至少 44×44 CSS px。

## 5. Win / Lose Conditions

没有失败状态。累计角位移达到 `1.65π` 即进入成功态，顶部标题保持不动，底部文字切换为“环已经闭合 / THE HALO CLOSES”，进度环扩张至目标球直径的 2.8 倍并在 1.8 秒内淡出；随后自动复原，可立刻再次体验。

## 6. Sound Effects

- 首次真实按下：Web Audio 生成 92 Hz 正弦波，音量 0.018，时长 80 毫秒，作为低沉接触反馈。
- 每跨过 25% 进度：生成 220/277/330 Hz 三角波中的对应一级，音量 0.012，时长 55 毫秒；同一级只播放一次。
- 完成：440 Hz 与 660 Hz 正弦波相差 65 毫秒叠加，音量分别为 0.018 与 0.012，时长 420 毫秒，快速起音并在 360 毫秒内指数衰减。
- 自动复原不播放声音，避免循环浏览时持续打扰；所有声音只能在用户手势后创建 AudioContext。
